#  Marketing Mix (4Ps) of Amal Jyothi College of Engineering  
## A Student Case Study Website

This project is a responsive multi-page website developed as part of a **Digital Marketing / Marketing Management assignment**.  
The website presents a detailed case study analysis of the **Marketing Mix (4Ps)** — *Product, Price, Place, and Promotion* — of **Amal Jyothi College of Engineering**.

The website is hosted live using **GitHub Pages** and demonstrates both **marketing knowledge** and **basic web development skills**.
